How to publish your changes

  1. Edit here — Add, Edit or Delete listings above. Your changes are saved in this browser straight away, and Preview on live site shows them on the website (only in this browser).
  2. Export — Click ⬇ Export listings.json. A file named listings.json downloads to your computer.
  3. Send it to Zenith AI (or your web person) — they replace assets/data/listings.json on the website and re-deploy. The changes then go live for everyone. Until then, visitors still see the old list.

Import: you can also load a listings.json file back into this page to keep editing. Reset to published throws away your unpublished changes and reloads the live list.

“Today's Recommended Properties” on the home page is a fixed pick of 12 listings — to change which ones are featured, ask Zenith AI. Photos: the site currently has 18 real property photos; more can be added from the Drive folders the same way.
